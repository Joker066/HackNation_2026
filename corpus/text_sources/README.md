# corpus/text_sources

One JSON file per document the system can cite (`<host>/<slug>-<hash>.json`): URL, title,
publisher, publication and retrieval dates, text, licence, storage type and catalogue row.

**These files are not covered by the project's own licence.** Each keeps the licence of its
publisher, recorded in its `license` field and in [`../sources.csv`](../sources.csv):

- gov.pl and CERT Polska material: **CC BY-SA 4.0**, © the respective public bodies;
- police and Maritime Office material: public sector information (Polish re-use act);
- kgsok.pl: excerpts only, © KG SOK;
- fact-check records: ClaimReview metadata only; the full fact-checks are at the linked URLs;
- EUvsDisinfo: excerpts, © European Union (EEAS).

Retention and deletion: see [`../../docs/sources.md`](../../docs/sources.md).
